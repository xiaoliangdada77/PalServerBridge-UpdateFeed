# 世界生成帕鲁文档

## type: "spawn_pal"

在世界指定坐标生成帕鲁实体（野生帕鲁，不属于任何玩家）。
可以引用 `pal/` 模板获取帕鲁属性，再通过内联字段覆盖。

## 格式

```json
{
    "type": "spawn_pal",
    "pal_template": "pal/Debug_SuperAnubis",
    "Location": {"X": 1000, "Y": 2000, "Z": 500},
    "Rotation": {"Pitch": 0, "Yaw": 90, "Roll": 0},
    "AdjustToFloor": true,
    "count": 1,
    "SaveParameter": {
        "CharacterID": "Kirin",
        "Level": 50
    }
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| **type** | string | 固定 "spawn_pal" |
| pal_template | string | 引用帕鲁模板路径 (如 "pal/Debug_SuperAnubis") |
| **Location** | object | **必填** 生成坐标 |
| Location.X | float | X 坐标 |
| Location.Y | float | Y 坐标 |
| Location.Z | float | Z 坐标 |
| Rotation | object | 朝向旋转 (默认全0) |
| Rotation.Pitch | float | 俯仰角 |
| Rotation.Yaw | float | 偏航角 |
| Rotation.Roll | float | 翻滚角 |
| AdjustToFloor | bool | 自动贴地 (默认true) |
| count | int | 生成数量 (默认1) |
| SaveParameter | object | 帕鲁保存参数。未使用模板时必填 |
| SaveParameter.CharacterID | string | 帕鲁ID。未使用模板时必填 |

## 说明

- `pal_template` 和 `SaveParameter.CharacterID` 至少提供一个
- 如果同时提供，`SaveParameter` 内联字段覆盖模板值
- 所有帕鲁属性字段 (Level, Rank, PassiveSkillList 等) 都应放在 `SaveParameter` 内覆盖
- `CharacterID` 不能放在 `data` 根层；根层格式会返回 `Missing SaveParameter.CharacterID`
- 生成的帕鲁为野生状态，不属于任何玩家
- `spawn_pal` 是世界生成操作，不需要 `steamid`，无人在线时也可以按坐标生成

## 使用示例

引用模板:
```json
{"key": "xxx", "data": {
    "type": "spawn_pal",
    "pal_template": "pal/Debug_SuperAnubis",
    "Location": {"X": 0, "Y": 0, "Z": 500}
}}
```

纯内联:
```json
{"key": "xxx", "data": {
    "type": "spawn_pal",
    "SaveParameter": {
        "CharacterID": "Kirin",
        "Level": 50,
        "IsRarePal": true
    },
    "Location": {"X": 1000, "Y": 2000, "Z": 500},
    "count": 5
}}
```
