# PalServerBridge 配置说明

## config.json

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| http_port | int | 8888 | HTTP 服务端口 |
| api_key | string | "change_me_to_a_secure_key" | API 密钥（必须修改） |
| log.global_level | string | "info" | 全局最低日志级别 |
| log.console_level | string | "info" | UE4SS 与游戏控制台日志级别 |
| log.file_level | string | "debug" | 文件日志级别 |
| log.file_enabled | bool | true | 是否启用文件日志 |
| log.max_files | int | 20 | 最多保留的日志文件数量 |
| log.async_write | bool | true | 是否异步写入日志文件 |
| game_api.use_rest_api | bool | true | 使用 REST API |
| game_api.rest_api_url | string | "http://127.0.0.1:8211/v1/api" | REST API 地址 |
| game_api.rest_api_username | string | "admin" | REST API 用户名 |
| game_api.rest_api_password | string | "" | REST API 密码 |
| update_notice.enabled | bool | true | 是否启用更新公告检查 |
| update_notice.feed_url | string | GitHub raw UPDATE.md | 远程更新源地址 |
| update_notice.timeout_ms | int | 3000 | 更新请求超时时间（毫秒） |
| i18n.language | string | auto | 语言代码，首次运行会把 auto 解析为系统语言 |

## 配置自动同步

- 新版本新增的配置项会自动添加到现有 config.json
- 旧版本废弃的配置项会自动删除
- 已修改的配置值会保留不变
- 类型不匹配时会重置为默认值
