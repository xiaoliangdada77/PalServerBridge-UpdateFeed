# 物品模板文档

## 目录: templates/item/

物品模板定义一种物品及其数量。属于第一层模板，不可引用其他模板。

## 格式

```json
{
    "type": "item",
    "ItemId": "SphereItem_Pal_Legend",
    "Count": 10
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| **type** | string | 固定 "item" |
| **ItemId** | string | **必填** 物品代码 |
| Count | int | 数量 (默认1) |

## 常用物品代码

| 代码 | 名称 |
|------|------|
| SphereItem_Pal_Legend | 传说球 |
| Gold_Coin | 金币 |
| Money | 游戏币 |
