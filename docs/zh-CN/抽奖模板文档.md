# 抽奖模板文档

## 目录: templates/lottery/

抽奖模板包含多个奖品，按权重随机抽取一个。属于第二层模板，可引用其他模板。

## 格式

```json
{
    "type": "lottery",
    "items": [
        {"template": "pal/max_anubis", "Weight": 100},
        {"type": "item", "ItemId": "Gold_Coin", "Count": 500, "Weight": 1000},
        {"template": "gift/starter_pack", "Weight": 50}
    ]
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| **type** | string | 固定 "lottery" |
| **items** | array | 奖品列表 |
| items[].Weight | int | 权重 (默认1000, 越大概率越高) |

## 概率计算

概率 = 该项Weight / 所有项Weight之和

例如: Weight 100 + 1000 + 50 = 1150
- 满配阿努比斯: 100/1150 = 8.7%
- 500金币: 1000/1150 = 87.0%
- 新手礼包: 50/1150 = 4.3%

## 说明

- 每个 item 可以是模板引用或内联定义
- 抽奖可以嵌套引用礼包或其他抽奖
- 系统会自动检测循环引用并阻止
