# 礼包模板文档

## 目录: templates/gift/

礼包模板包含多个物品/帕鲁，按顺序全部发放。属于第二层模板，可引用其他模板。

## 格式

```json
{
    "type": "gift",
    "items": [
        {"template": "pal/max_anubis"},
        {"template": "item/legend_sphere"},
        {"type": "pal", "CharacterID": "Kirin", "Level": 30, "count": 2},
        {"type": "item", "ItemId": "Gold_Coin", "Count": 1000}
    ]
}
```

## 说明

- `items` 数组中每一项可以是:
- **模板引用**: `{"template": "pal/xxx"}` 从文件加载
- **内联定义**: `{"type": "pal", "CharacterID": "xxx", ...}` 直接定义
- **模板+覆盖**: `{"template": "pal/xxx", "Level": 30}` 加载后覆盖部分字段
- 礼包可以嵌套引用其他礼包或抽奖模板
- 系统会自动检测循环引用并阻止
